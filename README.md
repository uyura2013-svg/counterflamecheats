# CounterFlame Companion

Android companion utility with a dark gaming-style interface.

## Features
- Local player nickname
- Manual match and win counter
- Sensitivity reference slider
- Crosshair style preview
- Personal notes
- General Android performance tips

This app is a standalone companion. It does not read, modify, inject into, or interact with CounterFlame or any other game process.

## Build
Push to `main` or run the **Build Android APK** workflow manually from the Actions tab. The debug APK is uploaded as the workflow artifact named **CounterFlame-Companion-APK**.
